 Campus Network Diagrams

This folder contains the network topology and architecture diagrams for the University of Limpopo Smart Campus Network project.

The network follows a hierarchical design consisting of:

- Core Layer
- Distribution Layer
- Access Layer
- Main Campus Network
- Satellite Campus Network
- Firewall and WAN connectivity
- IPSec VPN connection between the Main Campus and Satellite Campus
- Wireless, VoIP, server, IoT and CCTV infrastructure

The diagrams provide a visual representation of the network design implemented and tested in Cisco Packet Tracer.
